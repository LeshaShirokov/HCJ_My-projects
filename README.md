# МОИ ПРОЕКТЫ (Учебный проект)

Это учебный frontend-проект для будущего Django-приложения по управлению проектами.

## Ссылка на страницу:

[Ссылка на главную страницу](https://leshashirokov.github.io/HCJ_My-projects/)

## О проекте

Суть проекта овладеть базовыми навыками работы frontend-разработки освоив на базовом уровне работу с разметкой HTML, со стилями CSS, с языком программирования JS, с системой управления версиями Git и с работой на платформе GitHub.

## Технологии

- HTML5
- CSS3
- JavaScript
